## Simplification (`/simplify`, 2026-10-03)

Four reviews of the M1 code (reuse, simplification, efficiency, depth of the fixes) applied before the external review: runtime flowtable inspection lists only the flowtables (`nft -j list flowtables`, same JSON on 1.0.6 and 1.1.7) instead of the whole ruleset, and a reload lists them once for both configurations; the teardown order is an input of the diff instead of a sort in cleanup, with a unit test; `Layout::is_path_table` replaces an offset repeated in the reconciler; a reload removes the paths and probers of removed uplinks at once; test hooks are always compiled and do nothing without the feature; harness helpers for counters, sysctls, interface indexes, the CLI with the run's configuration, environment variables of spawned processes, run identifiers reserved by an exclusive directory and per-run directories owned by the topology; one cargo call per package in `run-suite.sh`. Not applied: sharing the restoration rule of cleanup and of the family handoff (they differ by design: errors, manifest, retries), merging the two third-party removal branches of the notification handler, running the nft inspections of a full reconciliation concurrently (event order), and replacing the kernel handoff test's convergence loop with the daemon's pass (a larger change, for M2).

Points for the specification review with the external reviewer (implementation choices the text does not state yet): `state_dir` cannot change on reload (FR-CFG-4 lists only the structural settings); a failure of an interface's sysctls makes its paths not ready with reason `route_install_failed` (FR-DISC-7 names only routes); `firewall.nft_path` ownership is checked in external mode too (FR-CFG-5).

Observed twice: AS-01 on Linux 6.1 gave A 55.5 % and, on 2026-10-04, 44.5 % in one sample of five (bound 45–55 %, 1,000 connections), not reproduced on reruns. With 1,000 connections the bound is ±3.2σ per sample, so a full validation (5 samples × 3 masks × 3 environments) failed by chance a few percent of the time. Resolved by SPEC v0.9 §14.3: the range applies to the aggregate of the five samples (±7σ), each sample within twice the half-width.
